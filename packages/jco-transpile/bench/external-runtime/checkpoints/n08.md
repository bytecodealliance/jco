# N08: 118 mapped variants with shared component scheduling

Historical measurements from the original stack; the rewritten trait-based branch requires fresh measurements for performance claims.

A later elevated process audit during N12 found eight orphan P3 CLI fixture workers from the initial N08 test run that remained alive during this checkpoint. Earlier claims of complete process isolation were not established. The original timing observations and findings are retained with an unquantified background-load limitation; size and source/hash audits do not depend on that claim. N14 now provides [separate clean frozen-input repair evidence](n14-historical-repair.md); the original observations below retain this limitation. See [the process audit and correction](n12-isolation-correction.json).

All 16 component variants now use named exports, bringing coverage to 118/274.
Selected initializers return the actual instance flags, trap cell, scheduling
owner and async-state Map. Component state receives its selected per-store
representation-table constructor, shared allocator and narrow trap/deadlock
views. Core suspending imports use these views directly; their three migrated
component bridges are removed. Lazy waitable creation remains until N09, and
task lookup capabilities remain until N11. A private stateless promise helper
keeps the core/component import graph acyclic. Inline remains the default.

The paired inline backpressure fix notifies a snapshot of registered handlers
and resolves each waiter only at zero, once, including reentrant notifications.
This changes the 24 nonempty/non-noise inline bundles from N07. Core-Wasm digests
remain unchanged. Earlier inline numbers cannot stand in for this revision.

Validation passed: 98 Rust tests and Clippy; 134 runtime unit cases plus the packed
consumer case; 138 focused cases including 20 Chromium cases; four Jco API/CLI
checks; the complete external suite with 814 passes and three existing skips;
and all 225 inline LTS cases. Installed NodeNext/Bundler consumers compare every
published module's actual JavaScript exports and value kinds with its standalone
declaration contract, compile literal contract copies without Node types/private
declarations, and verify selected behavior. Minimal imports access no optional
platform capabilities or unrelated state.

The initialization investigation ran sixteen separate serial diagnostic processes
after all timing children exited: inline/named, both bundlers, and numbers,
adder, resource and sharing workloads. Core compilation and shim preparation
preceded tracing; known answers were then verified. Import-time constructor
counts were zero in every case. Counts at instantiation and after known answers
match exactly within all eight pairs. Adder/resource initialization uses seven
Maps and one private symbol; sharing uses fourteen Maps and two symbols. Numbers
uses eleven Maps, two symbols, one DataView, ArrayBuffer, Uint8Array, Uint16Array
and TextEncoder. All other traced constructors are zero. The complete diagnostic
worker, hashes, declared owner graph and phase counts are in
[constructor traces](n08-constructor-traces.json).

The traces rule out extra instances of those native constructors in the tested
initialization paths. They do not count ordinary objects/array literals,
functions, class identities, lexical environments or Promise/native internals,
and therefore do not establish equal heap allocation or explain the full timing
penalty. Named initialization adds capability views and constructor-initializer
calls; the component class also retains its context for the transitional
waitable factory, which N09 removes. These are source-level candidates, not a
measured causal attribution. N14 must factor the remaining costs before making
an architectural speed or memory claim.

Isolated component controls select only their expected prerequisites: empty
owners create two Maps; may-leave, trap normalization and synchronous host tracking
create one each; the selected component class plus actual core/resource owners
creates six Maps and one symbol, without waitable/codec/scratch initialization.
Unused imports reduce to 31 bytes. Browser functional coverage passed; browser
timing and the complete historical/shared portfolio remain N14/N19 work.
