# N07: 102 mapped variants with selected core constructors and state

Historical measurements from the original stack; the rewritten trait-based branch requires fresh measurements for performance claims.

The remaining 52 core variants now use named exports, bringing coverage to
102/274. The public core subpath has 53 exports: the mapped operations and values
plus the selected file-compilation cache initializer. Constructors are initialized
once per relevant instantiation, preserving `new`, `instanceof`, native method
receivers and class statics. Task registers, memory lookup and conditional-JSPI
module storage are actual shared owners. Resource borrow/destructor operations
now receive those registers rather than bridges to migrated core operations.
Only narrow component/task capabilities remain inline. Inline remains the default.

The paired `RepTable.clear` fix releases only live shared indices and resets the
size; its regression and implementation apply to inline and named output. This
legitimately changes the 24 nonempty/non-noise inline bundles from N06. Core-Wasm
digests are unchanged. Matched historical comparisons must account for this fix.

Validation passed: 93 Rust tests and Clippy; 114 runtime/package tests plus four
additional conditional-trampoline cases; 122 focused generated cases including
20 Chromium cases; four Jco API/CLI checks; the complete external suite with
798 passes and three existing skips; and all 209 inline LTS tests. No isolated
functional rerun was needed to combine the final broad results. The initial
new integration run had two test-only assertion failures: the missing-export
checks now use Vitest rejection assertions and a native Node loader subprocess.
The original failed log is retained. Packed NodeNext/Bundler consumers and literal
contract copies compile without private declarations or ambient Node types.

Generated sync/async/direct, minified/unminified cases verify actual task-register
sharing, independent representation-table constructors/sentinels, error constructor
identity and payloads, native missing-export failures, and the existing host
`instantiateCore` callback signature. Four unit cases verify each conditional
trampoline's live selected module and lazy selected Instance/Suspending access.
The extended-fixture/toolchain gap recorded at N06 remains; no new extended
behavior coverage is claimed.

`b3c402fbec4ad85fbcd8a7d3d915eb44bf4d6ec77a3b002471c15d6fca0cee0b`.
The source manifest includes both central and nested core descriptors. All

Passing parity does not establish a performance benefit. This cohort flags
32 material startup penalties: parse and/or link+evaluation, with no material
initialization or warm-call gain or regression under the declared effect,
interval and identical-code noise rule. All estimates, ranges, intervals and
noise bounds are retained in [n07-analysis.json](n07-analysis.json), with input
and analysis-source hashes. This derived analysis exactly reproduces the
recorded findings; raw samples remain in the original archive.

For example, Rolldown/file numbers link+evaluation has a paired ratio of
1.2147, process range 1.1627–1.3492 and 95% interval 1.1627–1.3492, against a
9.69% noise bound. Absolute mode medians are 49.314 microseconds inline and
62.983 microseconds named; they still pass the independent `inline * 1.25 +
25 microseconds` budget. Mode medians and medians of within-process paired
ratios are different aggregations. Rolldown/file resource parse has paired ratio
1.1084 with interval 1.0880–1.1212, also a startup penalty. These are single-cohort
signals, not evidence of a universal effect or a resolution-path cause. Broader
attribution and the historical factory comparison remain N14 work. The
predeclared ten-process trigger (a parity failure or new material initialization/
warm-call regression) did not occur; no favorable retry replaced this cohort.

Used core scalar, error-payload and task-register controls allocate no traced
