Historical measurements from the original stack; the rewritten trait-based branch requires fresh measurements for performance claims.

The global WebIDL adapter now receives only its actual mutable proxy cache.
Importing the module and initializing the empty cache access no Proxy/Symbol
capability; the first adapter call creates its private symbols and proxy. Direct
module import destructuring uses the central contextual-call descriptor, with
cache setup before the call. Explicit instantiation uses supplied imports and
selects no unused WebIDL cache. Inline output remains the reference/default.

generated-runtime cases and 4 Jco API/CLI checks. The public self-contained

retains aliases, method receivers, argument unwrapping, reflection and the known
native-method destructuring limitation. Direct module reevaluation verifies
independent cache/proxy identities; explicit imports initialize none.
