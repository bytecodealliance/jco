# N02: 20 mapped variants with numeric and bitcast coverage

These measurements are historical evidence from the original stack. They do not
measure the rewritten trait-based branch; current validation uses the functional
matrix and intrinsic parity tests.

All 19 conversion variants now use named operations, alongside resource tableGet.
Strict numeric calls receive only their policy; bitcasts receive only their selected
per-instantiation aliased storage. Context-free calls have no dummy context. The
production default remains inline.

Functional validation passed: 87 Rust tests and Clippy; 21 runtime/package tests
including packed NodeNext/Bundler and standalone contracts; 747 external functional
tests (3 existing skips), 158 inline LTS tests, and 4 Jco API/CLI tests. The external
suite includes Chromium, P3 and WAST. Fixture repairs completed the custom numeric
validator and initialized Componentize's filesystem preopen before WIT path reads.
An initial full run exhausted disk space; its partial output was not accepted.
Only regenerable build intermediates/caches were removed, then the complete suites
were rerun successfully. Historical benchmark evidence and refs were preserved.

The scalar import control exposes retained code separately from allocations:
Rolldown emits 929 bytes, including the generic numeric validator behind the
strictness branch; Rollup reduces the same entry to 70 bytes and removes that
validation branch. Inspection of both saved bundles confirms this distinction.
Scalar imports construct zero maps, codecs or bitcast views. Each selected bitcast
initializer constructs exactly its own two views; unused imports retain only the
31-byte answer export. The current size penalties therefore do not demonstrate
eager scratch or unrelated-family initialization.

There is a repeated link-plus-evaluation penalty for Rolldown's file-URL variant
case: median process-paired ratios 1.0765 (95% interval 1.0507–1.0881) and 1.0589
(1.0286–1.0997) in the two runs. Both meet the predeclared relative material-effect
criteria, while remaining within the separate parity budget. Aggregate absolute
medians were 46.778/49.287 microseconds and 50.678/50.926 microseconds. Aggregate
medians and medians of paired ratios are different estimators, so these numbers
must not be combined into one inferred absolute penalty.

AST inspection finds 13 top-level arrow-function declarations in that named bundle
and none in its inline counterpart (both have two top-level function declarations).
This supports extra module-scope definition work as an explanation; it does not
isolate its exact timing cost. More detailed attribution belongs to N14. Two other
relative evaluation signals occurred only in the regression invocation; they are
not treated as replicated findings. Warm-call speedups remain inconclusive.
Negative memory observations are excluded, and no memory-saving claim is made.

These are same-revision inline/named results at 20 variants, not a matched
factory comparison or complete-coverage assessment. N01's one-variant baseline is
preserved. The full historical portfolio, matched factory control and browser
measurements remain scheduled at N13/N14; payload workloads follow the final
future/stream families.
