# N12: 166 mapped variants with explicit host-call contexts

Historical measurements from the original stack; the trait-based rewrite needs fresh measurements for performance claims.

The rewritten host provider uses `Provides<HostIntrinsic>` and the runtime's callback binding contract. Prepare captures the actual caller thread and creates an implicit callee thread. Start/return paths retain those identities across JSPI suspension and restore per-thread context slots. The callback driver is a static dependency shared with the task module; wait/poll use the static host event writer without a generated forwarding closure.

Validation of the rewrite includes 135 Rust tests, 235 runtime/package tests, 836 external component/conformance cases (three existing skips), 79 focused inline component cases, 24 browser provider cases and 48 bundler/functional cases. These checks validate behavior and bundle integrity; the original timing and size measurements below describe the historical stack.

All four host variants now use named exports. Prepare receives actual task
lookup/creation/register owners, the live may-block register and the selected trap constructor.
Async/sync start share task/register/component-index owners, component lookup and driver
capabilities. Async start additionally consumes the live blocking-depth register, registered
memories and SUBTASK event code. Contexts are stable per relevant store; selecting a start
operation alone does not initialize task constructors. The event writer is context-free and
receives only its actual memory, pointer and event operands.

The selected WebAssembly namespace remains the receiver of promising. Optional JSPI is read at a
cache miss, rather than during context construction; cached wrappers and direct async callees
avoid that getter. Canonical metadata remains after context binding, and FACT callbacks preserve
their null receiver and rest-argument order. Independent providers check actual contexts,
constructor/task/register sharing, separate stores, normalized encodings, captured memory,
eager/deferred states and known answers. Native Node module loading rejects missing selected
exports. Four browser cases drive sync-lowered and deferred async calls through default and
independent custom runtimes, each with separate stores.

Default wait/poll statically call the pure event writer, removing the last N09 event-writing
callback bridge. A sibling host-writer override does not intercept those defaults. The unchanged
task driver/unpack implementation moves to a private module and remains re-exported from the
task subpath, avoiding importing task class implementations merely to use driver defaults. The
public driver return type now accurately permits void or Promise<void>. Parsed
emitted-JavaScript audits preserve both task constructor algorithms, driver/unpack bodies and
the reviewed host transformation; array elisions remain intact. The actual built TypeScript
emitter is checked too. See [the source audit](n12-source-audit.json) .

The paired inline corrections normalize all three encoding metadata/constructor operands, store
the actual return memory and unwrap registered caller-memory metadata. Ten independent generated
regressions reproduced the old failures in both modes and pass after the fixes. Runtime cases
retain ToUint32 pointer behavior, bigint/invalid-encoding rejection before child creation, six
result-count conventions, same-slice return/trap and depth restoration, suspension/cache
behavior, caller-register restoration, registered-memory lowering, and little-endian bounded
event writes.

The actual Rust enum/binding inventory exactly matches the historical 166-variant set at
678ac430, rather than merely matching its count. The remaining 108 variants are precisely lift
29, lower 29, future 24 and stream 26. The standalone readonly structural contract, exact
JS/type namespaces, copied declarations, independent provider fixtures, packed NodeNext/Bundler
consumers and minimal denied-global imports include the host subpath. See
[the coverage audit](n12-coverage-audit.json) . No factory, operation registry, universal
options bag or generated old-arity facade is added. The lazy future predicate remains until N17.
Inline stays the production default.

tests with three existing skips, including all 24 browser provider cases and both unchanged
native-performance checks; 299 inline LTS cases; 50 explicit nested inline P3 cases in ten
