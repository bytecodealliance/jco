# Trait-based runtime stack audit

This stack was originally rewritten on `feat/trait-based-runtime-named-exports` at `facc70f2d9e6a5d620b3ae30e2a1d1d2161221c8`,
then rebased onto `upstream/main` at `7ae2325053ae64459a331a00721611111ee27d12` after that base merged.
Each branch implements its intent on the preceding branch. The rebase preserves main's async host-import ordering and zero-length stream validation in both runtimes.
The external runtime provides all 292 current intrinsic variants through `Provides<F>` and `IntrinsicRuntime`.
Inline generation remains the default; named external exports use runtime API version 1.

The rewrite preserves compact Latin-1/UTF-16 strings, executing-thread state, selected constructor identities,
resource ownership, canonical traps, synchronous host import completion, and conditional stream copies.
The final audit adds the trait base's generator and conditional host-import helpers and rejects stale coverage inventories.

Custom providers and browser import maps include every public family. The expanded functional portfolio covers
pending/rejected/nested futures, host stream payloads, guest stream payloads, and cancellation.
The standalone runtime type contract is checked by package consumers.

The [source audit](./n19-source-audit.json) records current source fingerprints, branch heads, original per-branch validation, and separate rebase validation.
No new accepted performance cohort is claimed. `original-n19*` and the `n19-focused-p3`/`n19-protocol` files
are explicitly historical records of the original stack. Timing collectors remain available separately from functional tests.
