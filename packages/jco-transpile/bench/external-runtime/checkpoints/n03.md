# N03: 22 mapped variants with a selected live DataView cache

Historical measurements from the original stack; these do not measure the
rewritten trait-based branch. Current checks validate functionality and allocations.

Both JavaScript helpers now use named exports. `emptyFunc` is context-free;
`dataView` receives only its per-instantiation mutable view owner. Loads and stores
use direct contextual calls, with no compatibility wrapper. Memory switching,
ordinary/shared growth, reentrant getters and independent stores preserve inline
behavior. Inline remains the production default.

Validation passed: 88 Rust tests and Clippy; 28 runtime/package tests including
packed consumers, release smoke and copied standalone contracts; 753 external
tests in 76 files (3 existing skips), including Chromium/P3/WAST; 164 inline LTS
tests; and 4 Jco API/CLI checks. Initial malformed WAT test fixtures failed before
execution and were corrected; their logs remain in the local replay archive.

Package/file sizes agree. Adder/resource/sharing sizes are unchanged from N02;
empty/noise controls remain byte-identical, and core Wasm matches in every pair.
Relative to N02, named numbers grows 171/172 raw bytes (Rolldown/Rollup), and
variants grows 338/343. The generated cache owner, initializer and explicit call
argument replace the inline cache closure. Rolldown adds two module-scope arrow
initializers: numbers grows from 11 to 13 and variants from 13 to 15. Both inline
bundles retain two top-level function declarations and no top-level variables.
Allocation tracing rules out unrelated eager-family initialization as the source
of these changes. These inspections identify added definitions/state plumbing;
they do not isolate its timing cost. Further attribution remains N14 work.

Rolldown's file-resolution numbers parse penalty repeats: median process-paired
ratios 1.0694 (95% interval 1.0141–1.1238) and 1.0916 (1.0038–1.1179), exceeding
the corresponding identical-code noise bounds of 5.19% and 8.29%. This meets the
predeclared relative material-effect rule while remaining within the separate
parity budget. The second run also has much higher absolute timings across modes;
these paired ratios must not be interpreted as stable absolute costs.

Several link/evaluation penalties occur only in the recording invocation; the
regression invocation instead flags Rolldown package-resolution variants. They
are preserved as individual signals, not replicated findings for those entries.
There is no replicated material warm-call improvement. Negative memory observations
are excluded, and the diagnostics do not support a memory-saving claim. This is a
22-variant same-revision comparison; matched factory and complete-coverage
assessments remain scheduled at N14/N19.
