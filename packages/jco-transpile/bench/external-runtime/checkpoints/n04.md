# N04: 32 mapped variants with independently selected string capabilities

Historical measurements from the original stack. The rewritten trait-based branch
also covers compact Latin-1/UTF-16 and requires fresh measurements for performance claims.

All ten string variants now use named operations or initialized codec values.
UTF-8 allocation and direct transcoding share the actual selected encoder;
UTF-16 allocation receives only its endianness capability. Decoder objects retain
their identity and method receivers. Codecs are selected independently, once per
relevant instantiation, with no ambient cache, factory or arity bridge. Both
remaining inline flat-string lowerers use explicit contextual calls. Inline
remains the production default.

Validation passed: 91 Rust tests and Clippy, 67 runtime/package tests, 82 focused
generated-runtime checks, 144 reached P3 lowerer regressions, 4 Jco API/CLI tests
and 177 inline LTS tests. Packed NodeNext/Bundler consumers, copied standalone
contracts, negative type fixtures, independent providers and release smoke cover
the new subpath. Unit and generated-component cases retain empty-string coverage.

The first full external attempt exposed two missed calls in still-inline string
lowerers, causing 58 failures. Both were corrected through the central descriptor,
with a dual-mode Rust regression and the reached P3 rerun. The corrected full
runs each had 765 passes and 3 existing skips: one had an ENOSPC write in an
argument-spillover fixture, and the next had one DOM browser timeout at the
original 60-second limit. Unchanged isolated argument-spillover (12 tests) and
browser (4 tests) runs passed. DOM passed in 48.733 seconds in the first corrected
full run and 57.313 seconds in isolation. No functional timeout or performance
threshold changed. All attempts remain archived. Validation combines the full
and isolated runs.

Disk recovery removed only regenerable task compiler caches and raw WASI guest
outputs after vendoring; active vendor/obj and historical evidence were retained.
Functional commands now consistently disable Cargo incremental caches to avoid
profile churn. The independent declarations and selected capability checks passed
before rebuilding fresh compiler/vendor artifacts for consumers.

from N03. Core Wasm matches within every pair. The recording invocation flags

Source inspection identifies added module-scope definition work: Rolldown numbers
grows from 2 top-level function declarations and 13 arrow initializers in N03 to

decoders for its actual transcoding graph. Constructor controls confirm selective
initialization. These observations identify retained definitions and owners;
exact timing attribution remains N14 work.
