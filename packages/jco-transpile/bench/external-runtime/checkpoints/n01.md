# N01: named-runtime measurement foundation

## Historical measurements from the pre-trait stack

The measurements below describe the original branch and are retained for provenance.
They are not measurements of the rewritten branch. The rewritten N01 validates the
complete functional smoke matrix separately from timing, fingerprints both trait
implementations and their callers, and uses runtime API version 1. No new performance
claim is made until a fresh, complete timing run is recorded.

This checkpoint maps only `Resource(ResourceTableGet)` (1/274). It establishes
measurement machinery before conversion expands. Inline remains the production
default. No claim about complete coverage or factory-versus-named performance
follows from this checkpoint.

The recorded checkpoint is
`4d0e982aade9d8f08ece8a35258c3ce3d091dbd40dc268dd0b529cf57a271eaa`.
Recording and a subsequent independent regression run both passed all 8 tests,
20 scenario/bundler/resolution entries, 100 fresh timing processes and 8 used/unused
import controls per invocation. Each timing process took 15 alternating pairs.
Both runs met all declared inline parity budgets. The first run was the baseline;
the second checked it without updating it. Both raw archives are retained locally:

- `bench/output/external-runtime-named/run-j3MKWz` (recording)
- `bench/output/external-runtime-named/run-akPZCc` (regression)

Each archive contains complete source snapshots, manifests, generated adapters,
core Wasm, minified bundles, retained-module/context inventories, per-process raw
samples, cold import and separate retained-store memory diagnostics. The frozen
historical factory baseline and old `bench/output/external-runtime` are untouched.
A preliminary failed run caught an invalid zero representation in the resource
workload; it was fixed before collecting the recorded checkpoint.

Linux x64, Intel Xeon 2.60 GHz; Node 24.21.0, Rust 1.99.0, TypeScript 7.0.2,
Rolldown 1.2.13, Rollup 4.64.1, Oxc 0.151.0. Hashes of the actual compiler/runtime,
lockfile, fixtures, options, mapping and benchmark implementation are in the
snapshot. Both package-export and file-URL resolution produced identical sizes.
Core Wasm matched between modes. No runtime dependencies remained external.

Sharing saves 69–71 raw bytes here while compressed sizes increase by 41–59 bytes.
That deterministic difference illustrates why raw, gzip and Brotli need separate
findings. The adder and empty component are unchanged; the scalar noise control
is byte-identical. Used `tableGet` bundles execute the known answer; unused imports
retain only the 31-byte answer export. Instrumented calls construct zero maps,
codecs or bitcast arrays.

No timing axis met the predeclared material-effect criteria (5%, interval excluding
1, effect beyond the identical-code noise control). Ratios and process-cluster 95%
intervals are in both summaries; apparent small differences remain inconclusive.
Memory deltas for empty/scalar controls contained negative GC observations and are
excluded from evidence. Resource/store heap diagnostics varied enough across
resolution/bundler runs that they establish no memory saving. Cold native import
plus initialization is diagnostic, without an acceptance budget.

The resource fixture retains an invalid-handle export in addition to create/read/drop;
its bytes differ from the earlier local pilot's smaller exported API. Those saved
pilot numbers are not a matched baseline for this workload. Browser functional
coverage passed at N00 with the same unchanged compiler/runtime. Browser timing,
the full historical portfolio, factory controls and payload workloads belong to
the later checkpoints described in the replay plan.
