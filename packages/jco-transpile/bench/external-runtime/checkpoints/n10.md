# N10: 137 mapped variants with shared error-context owners

Historical measurements from the original stack; the rewritten trait-based branch requires fresh measurements for performance claims.

A later elevated process audit during N12 found eight orphan P3 CLI fixture workers from the initial N08 test run that remained alive during this checkpoint. Earlier claims of complete process isolation were not established. The original timing observations and findings are retained with an unquantified background-load limitation; size and source/hash audits do not depend on that claim. N14 now provides [separate clean frozen-input repair evidence](n14-historical-repair.md); the original observations below retain this limitation. See [the process audit and correction](n12-isolation-correction.json).

All eleven error-context variants now use named exports: three selected
state/class initializers and eight operations. The selected global-table class
keeps its live static storage and creates its representation table lazily. Local
tables and table registrations are actual per-store Map/record owners. Handle
allocation shares the component's existing allocator. Contexts carry only the
global getter, component lookup, local-table capabilities and registrations
needed by each operation. Global reservation does not initialize component or
local state. Default operations call their static dependencies; overriding a
sibling export does not implicitly intercept their calls. No factory, operation
registry or new inline bridge is introduced. Inline remains the production default.

Lift/lower calls insert the selected contexts before operands. Existing
new/debug/drop callback bindings retain their null receiver and metadata order.
Transfer retains its bare function identity inline; named mode binds its context
with `void 0`. An independent composed-component regression first demonstrated
that a shadowed `undefined` identifier changes the callback receiver. It failed
with the initial named emitter and passes with the unshadowable expression.
The source and destination entries, reference counts, lazy state, string callback
failure ordering and selected-constructor identities retain inline behavior.
Pre-existing lowerer branches identified for the N16 ownership audit are not
claimed covered solely by the broad suites.

The final hardened compiler passed 106 Rust tests and Clippy; strict public
runtime and benchmark types; affected lint/format; 163 runtime/package cases
including installed NodeNext/Bundler, literal standalone declarations, negative
contracts and exact JS/type exports; all 18 new frontend cases; the complete
external suite with 846 passes and three existing skips; inline LTS with 257
passes; four explicit inline P3 error-context cases; and four CLI/API checks.
The full run includes browser provider coverage. Initial concurrent focused

by the clean final full run with one test-file worker. The completed test runs'
owned temporary roots were removed before timing; no functional/build processes
overlapped measurement. The extended fixture/toolchain gap recorded at N06
remains; no unavailable extended coverage is claimed.
