# N06: 50 mapped variants with live resource owners

Historical measurements from the original stack; the rewritten trait-based branch requires fresh measurements for performance claims.

All resource variants, shared handle tables and the core scope counter now use
named exports. Selected initializers return the actual allocator, tables,
scope-task map and mutable scope/borrow cells. Generated code reads and replaces
cell members directly. Removal and transfer receive narrow capabilities;
destructors receive lazy task creation/execution capabilities while tasks remain
inline. State is isolated per instantiation. Inline remains the production default.

Validation passed: 92 Rust tests and Clippy, 91 runtime/package tests, 100 focused
cases (including 20 Chromium cases) and 4 Jco API/CLI checks. Ported resource
regressions cover shared handle indices, LIFO reuse, zero representations,
replaced borrow lists, lender accounting and destructor success/failure cleanup.
Packed NodeNext/Bundler consumers and copied self-contained contracts cover the
expanded exports and reject missing or snapshot capabilities. Six generated
sync/async/direct, minified/unminified cases check fresh destructor context slots,
enclosing-task restoration, repeated disposal and independent store owners.

The full external invocation had 781 passes, 3 existing skips and three failures:
a DOM fixture timeout at 60.957 seconds and two old source assertions expecting
context-free removal calls. The assertions now accept the explicit context while
still requiring removal before destructor invocation and handle invalidation.
All three resource tests passed the isolated rerun. The unchanged DOM case passed
alone in 31.845 seconds under its original 60-second limit; the other three browser
cases passed in the full run. Inline LTS passed all 195 tests. Validation therefore
combines full and isolated results, with the original failures retained.

The extended command reported five ENOENT failures: `test/components/output` is
absent, as are the WASI SDK, MoonBit, wit-bindgen and wac tools needed to construct
those fixtures. No extended-fixture behavior coverage is claimed. Checked-in P3
resource, guest-to-guest, future/stream and context regressions passed the full run.

The first complete serial archive, `run-6NAODC`, passed all 9 harness checks,
32 matrix entries and 128 import controls, using five fresh timing processes per
entry and 15 alternating pairs per process. Its checkpoint key is
`0fe9f0ee0cfba1345b9a8c3dd5c5bb15c93468fc409f17ecc8ee3ef096195160`.
Collection took 428 seconds. Its observed baseline is preserved independently of
strict parity: **parse parity failed for Rolldown/file numbers**. Every size,
link+evaluation, initialization and warm-call budget passed. No budget changed.

For that parse case, absolute process-mode medians were 6.712560 ms inline and
8.831617 ms named, exceeding `inline * 1.25 + 0.025 ms`. The separate median of
within-process paired ratios was 1.0427 with 95% process-cluster interval
1.0059–1.2908, below the 5% material-effect floor at its point estimate and with
substantial uncertainty. These are different aggregations; the paired estimate
does not turn the absolute-cost gate failure into a pass.

The first cohort also flags numbers link+evaluation penalties: Rolldown/file
paired ratio 1.1476, interval 1.0766–1.2053, against 12.82% identical-code noise;
Rolldown/package ratio 1.2216, interval 1.1162–1.3287, against 13.45% noise. Both
meet the declared material-effect rule while remaining inside their separate
parity budget. They require confirmation rather than a causal attribution to
resolution: file and package bundles are byte-identical.

Review found a bootstrap defect: the old LCG's low bit alternated, forcing five
even and five odd process indices in every ten-process resample. Alternating
binary observations incorrectly produced a zero-width interval. The corrected
sampler uses xorshift32 full-word fractions; an analytical canary requires the
interval to include both outcomes. Reanalysis preserves all raw samples and
absolute gates, records input/source hashes, embeds its exact analysis sources,
and refuses to overwrite artifacts. Both cohorts' corrected estimates are in
[n06-reanalysis.json](n06-reanalysis.json); original emitted intervals/findings
remain archived for provenance and are superseded by that analysis. The upper
median convention for even process counts is unchanged.

Sharing reduces the added Rolldown raw-code cost from 1,086 bytes for one
resource component to 351 bytes for two sharing a bundle. It does not produce a
Brotli win over inline: the shared named chunks remain 369/347 bytes larger.
All three size axes pass their existing budgets independently. All 32 inline
bundle hashes equal N05; only the empty/noise named controls remain unchanged.
Required resource owners now appear in real task-bearing graphs, including adder;
that workload is not a no-selected-operation control. Empty/noise controls remain
byte-identical across modes.

Used cell controls are 210 bytes with Rolldown and 148 with Rollup; the empty
table-owner control is 82 bytes with either. These allocate ordinary objects and
arrays but no traced constructors. Shared allocation/removal controls are
1,224/1,115 bytes and construct exactly two Maps, with no codecs, scratch buffers
or task creation. Unused controls reduce to 31 bytes. These are isolated import
controls, not a claim that real components need no task/resource state.
