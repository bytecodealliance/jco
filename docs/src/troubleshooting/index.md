# Troubleshooting

When something goes wrong with a transpiled or componentized module, start here.

- [Common issues](./common-issues.md): known failure modes, what causes them, and how to resolve
  them.

If a problem is not covered, please [open an issue](https://github.com/bytecodealliance/jco/issues)
with the exact command, the Jco version, and the output you saw.
